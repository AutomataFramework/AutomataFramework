# AutomataFramework

A small, agent-first game framework for 2D and 3D web games.

Nothing to install yet. The first packages arrive soon. Follow along at https://automataframework.com.

The code is MIT (see `LICENSE`), except `packages/art`, which is GPL-3.0-or-later because the unfake.js core it
carries includes libimagequant. Games never load `packages/art`, and the pictures it makes are yours.
